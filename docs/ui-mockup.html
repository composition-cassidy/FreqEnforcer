What this shows

  • Layout: title bar (menus, processing status) · header (file + detected pitch) · 2 px progress line · waveform with pitch overlay · one settings column (Target, Mode, Voicing, Stretch, Advanced collapsed) · footer (transport, A/B, levels, undo/redo, export).
  • No modals in the core flow. Multisample and Preferences slide into the settings column with a back button. Toasts sit bottom-left of the waveform.
  • Harmonic limiter ceiling editor appears as a resizable pane under the waveform only while the limiter is enabled (Advanced › Harmonic limiter). It is the one canvas that needs node dragging.
  • Controls: label · tabular-mono value · native <input type=range> restyled (keyboard-accessible for free). Value is editable on click, double-click anywhere on the control resets, a dot marks non-default. Mode-specific controls (Amount / Retune / Vibrato / Formant / Vocal tract) show per mode; Voicing greys out on non-WORLD modes.
  • Tokens: the first <style> block is tokens.css. One accent (#3fb3ba dark / #157f86 light), 4 px grid, 2 px radius, 1 px borders, Segoe UI + Consolas with tabular-nums so numbers never jump.
  • Canvases size themselves from clientWidth × devicePixelRatio with ctx.setTransform(dpr,…) and a ResizeObserver, so 175 % DPI renders crisp and at the intended size.

Needs a decision from you

  • Pitch curve: the backend's pYIN already computes an F0 contour but only returns note/cents/Hz. The overlay needs /api/load-audio (and /api/process for the corrected curve) to also return a decimated f0_contour and a confidence value. Additive, response-only; existing fields unchanged. OK to add?
  • Voicing: adds optional voicing_mode to ProcessRequest / RenderMultisampleRequest, default null = today's per-mode behaviour (force for Hard, strict for Soft/VT/HNM), so golden tests stay bit-exact.
  • Accent colour: I kept the brand's teal, desaturated. Say the word if you'd rather have amber or neutral white-on-grey for selection.
  • Crossfade loop settings moved from hard-coded (6/10/2) to Advanced so the multisample render and "Find loop" share them. Fine, or keep them hidden?
  • Dropped: ThemeEditor + 5 JSON themes, the waveform "blob" note-lane view (replaced by the pitch overlay with a draggable target line), KnobControl (sliders only), the loading overlay dialog. The 1–7 mode keys, Ctrl+arrows and all current shortcuts stay.
